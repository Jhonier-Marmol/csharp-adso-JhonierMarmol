## Comparación de instrucciones: Python, JavaScript y C#

| Instrucción        |        Python        |            JavaScript            |               C#                 |
|--------------------|----------------------|----------------------------------|----------------------------------|
| Mostrar un mensaje | `print("Hola")`      | `console.log("Hola")`            | `Console.WriteLine("Hola");`     |
| Leer un dato       | `input("Nombre: ")`  | `prompt("Nombre:")`              | `Console.ReadLine()`             |
| Crear una variable | `edad = 17`          | `let edad = 17;`                 | `int edad = 17;`                 |
| Condición          | `if edad >= 18:`     | `if (edad >= 18) {}`             | `if (edad >= 18) {}`             |
| Repetición         | `for i in range(3):` | `for (let i = 0; i < 3; i++) {}` | `for (int i = 0; i < 3; i++) {}` |
| Función            | `def sumar(a, b):`   | `function sumar(a, b) {}`        | `int Sumar(int a, int b) {}`     |

Esta tabla muestra que los tres lenguajes permiten realizar operaciones similares, aunque su sintaxis cambia. En C# se utilizan tipos de datos y punto y coma en muchas instrucciones, mientras que Python utiliza la indentación para organizar los bloques de código.
